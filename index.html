    Neue Rezepte als JSON importieren, aus einer passenden Rezeptdatei.

    Datenschutz

    Rezepte werden lokal im Browser auf diesem Gerät gespeichert. Es gibt keinen Server und keine Anmeldung. Sichere deine Rezepte regelmäßig mit der vollständigen Backup-Funktion, insbesondere vor dem Löschen von Safari-Websitedaten.
